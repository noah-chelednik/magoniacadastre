Checking a file

Each file's SHA-256 checksum is beside it, under its description. Every checksum is also in one file, SHA256SUMS.txt: one line per file, each named by its path in the downloads folder. Kept in those folders, the files are confirmed all at once by sha256sum -c SHA256SUMS.txt.
